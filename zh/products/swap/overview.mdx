[L2Pass Swap](https://swap.l2pass.com/) 在区块链之间转移代币，重点是稳定币。每笔兑换，它都会向多家独立路由提供方请求报价，按你的到账金额排序并排展示，你只需确认一次即可执行所选路由。

L2Pass 从不托管你的代币。每笔兑换都由第三方跨链桥、求解器网络和流动性来源在其自己的基础设施上执行。

## 支持的网络和资产

L2Pass Swap 目前支持 **Ethereum、Bitcoin、Zcash、Tron、Solana、TON、BNB Chain、Arbitrum、Base、Polygon、Optimism、Avalanche、Plasma 和 HyperEVM**。

稳定币（USDT、USDT0、USDC、DAI 等）是重点，但你也可以兑换 ETH、BTC、SOL、ZEC、TRX、BNB、AVAX 和 POL 等主流资产。可用的代币、网络和路由随时可能变化；[兑换界面](https://swap.l2pass.com/)始终显示最新列表。

## 路由如何运作

当你请求报价时，L2Pass 会同时询问多个路由渠道，并展示所有能完成你兑换的路由，按你将收到的金额排序：

- **L2Pass RFQ by NEAR Intents：** 通过 [NEAR Intents](https://near.org/intents) 网络进行询价（RFQ）路由，求解器和做市商竞争执行你的兑换。
- **L2Pass Private：** 同一个求解器网络，在机密环境中执行。参见[私密兑换](#private-swaps)。
- **USDT Native Bridge：** 基于 LayerZero 的原生 USDT0 转账，包括从 Tron 转出。
- **USDC Native Bridge：** 通过 Circle CCTP V2 转移原生 USDC，提供 Standard 和 Fast 两种模式。
- **聚合器和意图网络：** LI.FI、LI.FI Intents、Relay、Aori 和 OKX DEX 聚合器。

每张路由卡片都会显示预计到账、最少到账、预计时间和该路由的费用，方便你选择最合适的一条。部分路由设有最低兑换金额；如果你的金额低于该值，路由会显示为不可用，并标出最低金额。

## 兑换如何执行

根据路由不同，兑换有两种执行方式：

- **钱包交易：** 你在钱包中签署一笔交易，路由的合约在链上完成兑换和跨链。
- **充值地址：** 对于 RFQ 和 Private 路由，你把代币发送到为这次报价生成的一次性充值地址。你可以从已连接的钱包发送，也可以通过地址或二维码从任意钱包或交易所手动转账。如果从交易所发送，请确认到账金额与报价一致，因为部分交易所会扣除提现手续费。之后兑换会依次经过 *Awaiting deposit*、*Deposit confirmed* 和 *Complete* 状态，你可以在 **Recent swaps** 中跟踪。

对于充值地址路由，你还需要设置一个源链上的退款地址。如果兑换无法完成，提供方会把你的充值退回到该地址。

## 兑换需要多长时间

大多数兑换在几秒到几分钟内完成，每张路由卡片会在确认前显示预计时间。

- **Relay、Aori 和 CCTP Fast：** 几秒到约一分钟。
- **L2Pass RFQ 和 L2Pass Private：** 30 秒到几分钟；涉及 Bitcoin 或 Zcash 时更久，因为需要等待区块确认。
- **USDT0：** 几分钟。
- **CCTP Standard：** 最长 20 分钟，需要等待区块最终确认。

网络拥堵或提供方故障可能导致兑换时间超过预计。

## 滑点和价格影响

**价格影响（price impact）** 是交易规模相对于可用流动性造成的价格变动。比较多个渠道有助于降低价格影响。

**滑点（slippage）** 是报价价格与最终成交价格之间的差额。

- **滑点容忍度：** 默认容忍度为 **0.05%**，你可以在任意路由卡片中修改。
- **固定到账：** 部分路由（例如原生 USDT0 和 USDC 跨链桥）到账金额固定，因此不涉及滑点。
- **最少到账：** 每张路由卡片都会显示最少到账，即在你的容忍度范围内的最差结果。如果价格变动超出该范围，兑换不会执行：链上路由会回滚，充值地址路由会把充值退回到你的退款地址。

<a id="fee-structure"></a>

## 费用结构

路由卡片会在你确认前显示本次兑换的实际费用。**目标网络上的预计到账金额已包含所有费用**，源链 Gas 和可能存在的跨链消息费除外，这两项需要另外支付。

### L2Pass 手续费

| 兑换类型 | L2Pass 手续费 |
| :-- | :-- |
| 稳定币兑换（任意路由） | **0%** |
| 其他资产 | **最高 0.2%** |
| 私密兑换，任意资产（替代 0% 或 0.2%，而非额外收取） | **最高 0.3%** |

### 合作方和网络费用

路由合作方（跨链桥、求解器网络、聚合器和流动性提供方）可能收取自己的费用。L2Pass 不控制这些费用；最新信息请查阅各提供方的文档。

每笔区块链交易还需要以原生代币（如 ETH、POL、BNB 或 TRX）支付网络费（Gas）。Gas 费归网络所有，不归 L2Pass，且不予退还。

<a id="private-swaps"></a>

## 私密兑换

私密兑换会把你的兑换放在机密执行环境中，而不是公开环境中执行，从而减少公开区块链上可见的信息。这一功能由第三方协议 NEAR Intents 提供支持。

- **不是匿名：** 发送给提供方的请求中仍包含你的公开钱包地址。
- **相同筛查：** 私密兑换与公开兑换的筛查完全相同，在报价时和充值后都会进行。
- **手续费：** 私密兑换的 L2Pass 手续费最高 0.3%（替代 0% 或 0.2%，而非额外收取）。与所有费用一样，它已包含在报价显示的金额中。

详情请参阅 [Terms of Service](https://l2pass.com/terms-of-service) 和 [Privacy & AML Principles](https://l2pass.com/privacy-policy)。

## 全部成交或全额退款

兑换要么全部完成，要么不执行；失败的兑换会自动退款。

- **不部分成交：** L2Pass 不使用部分成交。兑换要么全部完成，要么不执行。
- **退款：** 如果充值地址兑换无法完成，例如价格变动超出容忍度或报价过期，提供方会把你的充值退回到退款地址，并扣除提供方和网络费用。失败的钱包交易会回滚，已支付的 Gas 不予退还。
- **合规审查：** 每笔兑换都会被筛查，无需 KYC。在 L2Pass RFQ 和 L2Pass Private 上，被标记的地址拿不到报价。到账后才被标记的充值不会退回，而是冻结审核，你需要向 NEAR Intents 支持团队提交工单处理。参见[筛查如何运作](/zh/products/swap/learn/failed-swaps-and-refunds#how-screening-works)。
