L2Pass 一步就能把你的代币转到另一条区块链：把 USDT 从 Tron 转到 Ethereum，把 BTC 换成 USDT，把 USDC 转到 Solana。它支持 **14 条网络**，包括 Bitcoin、Zcash、Tron、Solana 和 TON，并且可以选择公开兑换或私密兑换。

每次兑换，L2Pass 都会向多条路由请求报价，并在你确认之前显示每条路由能给你多少、收取多少费用。L2Pass 从不托管你的资金。稳定币兑换的 L2Pass 手续费为 **0%**。钱包和应用可以通过 **L2Pass Swap API** 获得同样的路由能力。

| 你想要 | 使用 L2Pass |
| :-- | :-- |
| 在网络之间转移稳定币 | 在 Tron、Ethereum、Solana、TON、BNB Chain、各类 L2 等网络之间转移 USDT 和 USDC，L2Pass 手续费 0% |
| 原生兑换主流资产 | Bitcoin 上的 BTC、Zcash 上的 ZEC，以及 ETH、SOL 等资产，与稳定币互换，你这边无需使用包装代币 |

| 在你的产品中加入兑换 | 集成 Swap API，或推荐用户并分享手续费 |

## 工作原理

每次报价，L2Pass 都会同时询问多条独立路由，并按你实际到账的金额排序：

- **L2Pass RFQ 和 L2Pass Private by NEAR Intents：** 求解器（solver）和做市商竞争执行你的兑换。
- **原生跨链桥：** 基于 LayerZero 的 USDT0，以及用于 USDC 的 Circle CCTP。
- **聚合器和意图网络：** LI.FI、Relay、Aori 和 OKX DEX 聚合器。

确认之前，你可以看到每条路由的到账金额、最少到账、预计时间和费用。显示的金额已扣除费用，只有源链 Gas 和可能存在的跨链消息费需要另外支付。[路由如何比较 →](/zh/products/swap/learn/compare-routes)

## 为什么选择 L2Pass

- **多个报价，而不是一个。** 每笔兑换都会同时获得 NEAR Intents 求解器、原生跨链桥和聚合器的报价，并按到账金额排序。
- **覆盖所有链，不只是 EVM。** Bitcoin、Zcash、Tron、Solana 和 TON 与 Ethereum 及其 L2 并列。
- **需要时就能保护隐私。** 私密兑换使用同一个界面，筛查方式与公开兑换相同。
- **非托管。** L2Pass 从不持有你的代币或私钥。无需账户，无需 KYC。
- **费用透明。** 稳定币兑换 0%，其他资产最高 0.2%，私密兑换最高 0.3%。[费用说明 →](/zh/products/swap/learn/fees)
