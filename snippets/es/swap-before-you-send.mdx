- **Reembolsos.** Si una ruta de wallet falla, la transacción se revierte y no se mueve ningún token, pero el gas que pagaste se pierde. Si una ruta con dirección de depósito no puede completarse, el proveedor devuelve tu depósito a la dirección de reembolso, descontando las comisiones del proveedor y de la red.
- **Sin ejecución parcial.** L2Pass no usa ejecución parcial. Un swap se completa entero o no se ejecuta.
- **Sin KYC, el mismo control para cada swap.** No necesitas cuenta ni KYC. En L2Pass RFQ y L2Pass Private, una dirección marcada no recibe cotización, así que no se envía nada. Un depósito marcado después de llegar queda retenido para revisión en lugar de reembolsarse; lo resuelves con el soporte de NEAR Intents. Consulta [Swaps fallidos y reembolsos](/es/products/swap/learn/failed-swaps-and-refunds#how-screening-works).
