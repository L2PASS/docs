# L2Pass Docs

Source for [docs.l2pass.com](https://docs.l2pass.com), the documentation for [L2Pass Swap](https://swap.l2pass.com): a non-custodial interface for cross-chain and private token swaps, with a focus on stablecoins.

The site is built with [Mintlify](https://mintlify.com). Every push to `main` deploys to production automatically.

## What's inside

| Path | What it is |
| :-- | :-- |
| `docs.json` | Site config: navigation, redirects, colors, navbar and footer |
| `index.mdx` | Home page |
| `products/swap/overview.mdx`, `faq.mdx` | How L2Pass Swap works: routes, fees, private swaps, refunds |
| `products/swap/guides/` | Step-by-step route guides (USDT Tron to Ethereum, USDC with CCTP, BTC to USDT and more) |
| `products/swap/learn/` | Explainers: fees, L2Pass RFQ by NEAR Intents, slippage, refunds, USDT networks, Swap API |
| `resources/` | Contracts, support and brand assets |
| `images/`, `logo/`, `brand_assets/` | Static assets |

Pages under `products/yield`, `products/yield-loop` and some files in `resources/` are legacy and are not in the navigation. Mintlify still serves any `.mdx` file in the repo by its URL, so delete a page or mark it `hidden: true` if it must not be public.

## Editing

- Add a page as an `.mdx` file and list it in `docs.json` under `navigation`, or it won't appear in the sidebar.
- When you move or rename a page, add a redirect to `redirects` in `docs.json` so old links keep working.
- Keep facts in line with the live app and the [Terms of Service](https://l2pass.com/terms-of-service): fees, routes and refund rules are quoted by users and AI tools.
- `llms.txt`, `llms-full.txt` and the sitemap are generated by Mintlify. Don't add them to the repo.

## Local preview

Install the [Mintlify CLI](https://www.npmjs.com/package/mint):

```bash
npm i -g mint
```

From the repo root, where `docs.json` is:

```bash
mint dev
```

Open `http://localhost:3000`. Before you open a pull request, run:

```bash
mint validate
mint broken-links
```
