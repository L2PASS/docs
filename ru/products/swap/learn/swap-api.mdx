L2Pass SwapKit API позволяет кошелькам, приложениям и AI-агентам добавить кросс-чейн свапы в свой продукт. Он работает так же, как L2Pass RFQ by NEAR Intents: вы запрашиваете котировку, получаете одноразовый адрес депозита, а пользователь платит с любого кошелька или биржи. Для каждой котировки API возвращает комиссию платформы, вашу партнёрскую комиссию и чистую сумму на выходе, а об изменениях статуса сообщает подписанными вебхуками. Для доступа нужен партнёрский API-ключ, который выдаётся при подключении. Справочная документация: [api.l2pass.com/docs](https://api.l2pass.com/docs).

## Что можно построить

API подойдёт любому продукту, который принимает токены в одной сети и доставляет в другой.

- **Кошельки:** кросс-чейн свапы стейблкоинов внутри вашего кошелька, включая Tron, Solana, Bitcoin и Zcash.
- **Платёжные приложения:** принимайте USDT в одной сети и проводите расчёт в другой.
- **Биржи и мерчанты:** схемы с адресом депозита, которые работают с любого кошелька или биржи.
- **AI-агенты:** получение котировок и исполнение свапов через REST API.

## Эндпоинты

Семь REST-эндпоинтов покрывают активы, оценки, котировки, статусы и ваш партнёрский аккаунт.

| Эндпоинт | Что делает |
| :-- | :-- |
| `GET /v1/assets` | Список поддерживаемых активов и сетей |
| `POST /v1/swap/estimate` | Оценка без адреса депозита |
| `POST /v1/swap/quote` | Обязывающая котировка с одноразовым адресом депозита |
| `GET /v1/swap/status/{quoteId}` | Статус: PENDING, COMPLETED, FAILED или REFUNDED |
| `GET /v1/partner/me` | Ваш партнёрский профиль и лимиты |
| `GET /v1/partner/transactions` | Список ваших свапов |
| `GET /v1/partner/analytics` | Аналитика использования |

Базовый URL: `https://api.l2pass.com`. Передавайте ключ в заголовке `X-API-Key`. Полная спецификация OpenAPI в [справочнике API](https://api.l2pass.com/docs).

## Как проходит свап через API

Свап через API идёт по той же схеме, что и в приложении: котировка, депозит, статус.

<Steps>
  <Step title="Получите оценку">
    Вызовите `POST /v1/swap/estimate` с исходным и целевым активами и суммой, чтобы показать пользователю, сколько он получит.
  </Step>

  <Step title="Запросите котировку">
    Вызовите `POST /v1/swap/quote` с адресами получателя и возврата. Ответ содержит одноразовый адрес депозита и разбивку комиссий: `platform_fee`, `partner_fee`, `total_fee` и `net_output`.
  </Step>

  <Step title="Дайте пользователю заплатить">
    Пользователь отправляет сумму из котировки на адрес депозита с любого кошелька или биржи.
  </Step>

  <Step title="Отслеживайте статус">
    Опрашивайте `GET /v1/swap/status/{quoteId}` или получайте вебхуки, подписанные HMAC-SHA256 в заголовке `X-Webhook-Signature`.
  </Step>
</Steps>

## Комиссии, лимиты и возвраты

Партнёрскую комиссию вы задаёте сами, а у вашего ключа свои лимиты запросов.

- **Партнёрская комиссия.** Можно добавить свою комиссию, она возвращается в каждой котировке как `partner_fee_bps` и `partner_fee`.
- **Лимиты запросов.** Лимиты задаются для каждого партнёра отдельно для котировок и запросов статуса. При превышении API возвращает 429 с заголовком `Retry-After`.
- **Ротация ключа.** Сменить ключ можно через `POST /v1/partner/rotate-key`.
- **Возвраты и сбои.** Если свап не может завершиться, провайдер возвращает средства на адрес возврата, и статус становится REFUNDED. Помеченные адреса не получают котировку. Депозит, помеченный после поступления, не возвращается, а удерживается на проверке, и пользователь решает вопрос через поддержку NEAR Intents. См. [Как работает проверка](/ru/products/swap/learn/failed-swaps-and-refunds#how-screening-works).

## FAQ

<AccordionGroup>
  <Accordion title="Как получить API-ключ?">
    API-ключи выдаются при подключении партнёра. Чтобы запросить доступ, свяжитесь с [поддержкой L2Pass](/ru/resources/support).
  </Accordion>

  <Accordion title="API хранит средства пользователей?">
    Нет. Пользователи платят на одноразовый адрес депозита для своей котировки, а свап исполняют солверы в NEAR Intents. L2Pass никогда не хранит токены или приватные ключи пользователей.
  </Accordion>

  <Accordion title="Можно ли зарабатывать комиссию на свапах?">
    Да. Задайте партнёрскую комиссию, и каждая котировка вернёт её как `partner_fee_bps` и `partner_fee` рядом с комиссией платформы.
  </Accordion>

  <Accordion title="Есть ли SDK?">
    Да, `@l2pass/swapkit-sdk` в npm. Подробности в [справочнике API](https://api.l2pass.com/docs).
  </Accordion>
</AccordionGroup>
