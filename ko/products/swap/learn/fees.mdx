[L2Pass Swap](https://swap.l2pass.com/)은 스테이블코인 스왑에는 경로와 관계없이 L2Pass 수수료 0%, 기타 자산에는 최대 0.2%, 비공개 스왑에는 최대 0.3%를 부과합니다. 비공개 수수료는 0% 또는 0.2% 대신 적용되며 추가로 붙지 않습니다. 라우팅 파트너와 블록체인은 자체 수수료를 부과하며, 확인 전 견적에 표시되는 수령액에는 이미 포함되어 있습니다. 출발 체인 가스와 브리지 메시지 수수료(있는 경우)만 별도로 냅니다.

## L2Pass 수수료

L2Pass가 직접 부과하는 유일한 수수료입니다. 자산 종류와 비공개 스왑 여부에 따라 달라집니다.

| 스왑 | L2Pass 수수료 |
| :-- | :-- |
| 스테이블코인 스왑(USDT, USDC 등), 모든 경로 | **0%** |
| 기타 자산(ETH, BTC, SOL, ZEC 등) | **최대 0.2%** |
| 비공개 스왑, 모든 자산 | **최대 0.3%**(0% 또는 0.2% 대신 적용, 추가 아님) |

## 견적에서 볼 수 있는 모든 수수료

견적에는 최대 다섯 가지 수수료가 포함될 수 있습니다. 앞의 세 가지는 수령액에서 차감됩니다. 뒤의 두 가지는 지갑에서 직접 내며 경로 카드에 표시됩니다.

| 수수료 | 부과 주체 | 지불 방식 |
| :-- | :-- | :-- |
| L2Pass 수수료 | L2Pass | 수령액에 포함 |
| 제공자 수수료 | NEAR Intents, LI.FI, Relay 등 라우팅 파트너 | 수령액에 포함 |
| 도착 네트워크 수수료 | 도착 블록체인 | 수령액에 포함 |
| 브리지 메시지 수수료 | LayerZero 기반 USDT0 등 일부 브리지 | 출발 체인 네이티브 토큰으로 지불, 경로 카드에 표시 |
| 출발 가스 | 출발 블록체인 | 지갑에서 네이티브 토큰(ETH, TRX, BNB 등)으로 지불, 경로 카드에 표시 |

L2Pass는 파트너 수수료나 네트워크 수수료를 통제하지 않습니다. 최신 내용은 각 제공자를 확인하세요. 경로 카드에는 항상 스왑의 실제 수수료가 표시됩니다.

## 실제 견적 예시

2026년 10월 19일(약 16:55 UTC) 테스트 견적에서 다음 수수료가 확인되었습니다. 실시간 견적에는 해당 페어와 금액의 현재 수치가 표시됩니다.

| 스왑 | 경로 | L2Pass 수수료 | 기타 수수료 | 수령액 |
| :-- | :-- | :-- | :-- | :-- |
| 1,000 USDC, Arbitrum → Base | L2Pass RFQ | 0 | NEAR Intents 수수료 0.1 USDC, 네트워크 수수료 0.0024 USDC | 999.80 USDC |
| 1,000 USDC, Arbitrum → Base | L2Pass Private | 3 USDC(0.3%) | NEAR Intents 수수료, 네트워크 수수료 0.0024 USDC | 998.20 USDC |
| 1,000 USDC, Arbitrum → Base | USDC 브리지(CCTP Fast) | 0 | 네트워크 수수료 0.19 USDC | 999.81 USDC |
| 1,000 USDT, Ethereum → Tron | USDT native bridge(USDT0) | 0 | 약 0.005 ETH(약 11.92 USD)의 LayerZero 메시지 수수료, ETH로 지불 | 999.7 USDT |
| Ethereum의 0.5 ETH → Arbitrum의 USDC | L2Pass RFQ | 0 | NEAR Intents 수수료 0.001 ETH, 네트워크 수수료 0.0053 USDC | 1,197.00 USDC |
| Ethereum의 0.5 ETH → Arbitrum의 USDC | Relay | 0.1%(약 1.20 USD) | 약 1.34 USD의 Relay 수수료 | 1,195.67 USDC |

수령액에는 각 제공자가 제시한 가격도 반영되므로, 나열된 수수료가 차이 전체와 항상 일치하지는 않습니다.

주목할 점 두 가지:

- **페어가 다르면 이기는 경로도 다를 수 있습니다.** ETH 예시에서 L2Pass RFQ는 모든 페어에서 가장 저렴한 경로가 아님에도 가장 많은 금액을 제시했습니다.
- **수령액 밖에서 내는 수수료도 보세요.** Ethereum에서 Tron으로는 USDT0의 수령액이 가장 높았지만 메시지 수수료를 ETH로 별도로 냅니다. L2Pass는 가스 이후 실제로 받는 순가치로 경로를 정렬하므로 L2Pass RFQ를 맨 위에 두었습니다.

## 내 스왑의 수수료 확인 방법

아무것도 보내기 전에 세 단계로 정확한 금액의 수수료를 모두 확인할 수 있습니다.

<Steps>
  <Step title="견적 요청">
    [swap.l2pass.com](https://swap.l2pass.com/)에서 출발과 도착 토큰, 네트워크를 고르고 금액을 입력하세요.
  </Step>

  <Step title="경로 카드 열기">
    각 경로 카드에는 예상 수령액, 최소 수령액, 예상 시간, 해당 경로의 수수료 내역이 표시됩니다.
  </Step>

  <Step title="비교하고 확인">
    경로는 수령액 순으로 정렬됩니다. 맨 위 경로를 고르거나, 속도가 더 중요하면 더 빠른 경로를 고르세요. 표시된 금액은 L2Pass, 제공자, 도착 네트워크 수수료를 뺀 실제 수령액입니다.
  </Step>
</Steps>

## 가스, 환불, 슬리피지

가스는 스왑이 실패해도 돌려받을 수 없는 유일한 비용입니다.

- **가스는 환불되지 않습니다.** 온체인 경로가 되돌려지면 토큰은 교환되지 않지만 출발 가스는 소모됩니다.
- **환불과 수수료.** 입금 주소 경로를 완료할 수 없으면 제공자가 입금액을 환불 주소로 돌려보내며, 제공자 수수료와 네트워크 수수료가 차감될 수 있습니다.
- **슬리피지는 수수료가 아닙니다.** 기본 슬리피지 허용치는 0.05%이며 어느 경로 카드에서든 바꿀 수 있습니다. 최소 수령액을 정하며, 고정 수령액 경로에는 영향을 주지 않습니다.
- **거래소에서 보내는 경우.** 일부 거래소는 보내는 금액에서 출금 수수료를 차감합니다. 도착 금액이 견적과 일치하는지 확인하세요.
