L2Pass SwapKit API를 이용하면 지갑, 앱, AI 에이전트가 자체 제품에 크로스체인 스왑을 추가할 수 있습니다. L2Pass RFQ by NEAR Intents와 같은 방식으로 작동합니다. 견적을 요청하면 일회용 입금 주소를 받고, 사용자는 어떤 지갑이나 거래소에서든 결제합니다. API는 견적마다 플랫폼 수수료, 파트너 수수료, 순수령액을 반환하고, 상태 변경을 서명된 웹훅으로 알려줍니다. 이용하려면 온보딩 때 발급되는 파트너 API 키가 필요합니다. 레퍼런스 문서는 [api.l2pass.com/docs](https://api.l2pass.com/docs)에 있습니다.

## 만들 수 있는 것

한 네트워크에서 토큰을 받아 다른 네트워크로 전달하는 모든 제품에서 API를 사용할 수 있습니다.

- **지갑:** Tron, Solana, Bitcoin, Zcash를 포함해 지갑 안에서 크로스체인 스테이블코인 스왑.
- **결제 앱:** 한 네트워크에서 USDT를 받고 다른 네트워크에서 정산.
- **거래소와 가맹점:** 어떤 지갑이나 거래소에서도 작동하는 입금 주소 흐름.
- **AI 에이전트:** REST API로 스왑 견적을 받고 실행.

## 엔드포인트

7개의 REST 엔드포인트가 자산, 예상치, 견적, 상태, 파트너 계정을 다룹니다.

| 엔드포인트 | 기능 |
| :-- | :-- |
| `GET /v1/assets` | 지원 자산과 네트워크 목록 |
| `POST /v1/swap/estimate` | 입금 주소 없이 예상치 반환 |
| `POST /v1/swap/quote` | 일회용 입금 주소가 포함된 확정 견적 반환 |
| `GET /v1/swap/status/{quoteId}` | 상태 반환: PENDING, COMPLETED, FAILED, REFUNDED |
| `GET /v1/partner/me` | 파트너 프로필과 한도 반환 |
| `GET /v1/partner/transactions` | 내 스왑 목록 |
| `GET /v1/partner/analytics` | 사용량 분석 반환 |

기본 URL: `https://api.l2pass.com`. 키는 `X-API-Key` 헤더로 보냅니다. 전체 OpenAPI 명세는 [API 레퍼런스](https://api.l2pass.com/docs)에 있습니다.

## API로 스왑하는 방식

API 스왑은 앱에서의 스왑과 같은 흐름을 따릅니다. 견적, 입금, 상태 순입니다.

<Steps>
  <Step title="예상치 받기">
    출발 자산, 도착 자산, 금액으로 `POST /v1/swap/estimate`를 호출해 사용자에게 수령액을 보여줍니다.
  </Step>

  <Step title="견적 요청">
    수신 주소와 환불 주소로 `POST /v1/swap/quote`를 호출합니다. 응답에는 일회용 입금 주소와 수수료 내역(`platform_fee`, `partner_fee`, `total_fee`, `net_output`)이 포함됩니다.
  </Step>

  <Step title="사용자 결제">
    사용자가 어떤 지갑이나 거래소에서든 견적 금액을 입금 주소로 보냅니다.
  </Step>

  <Step title="상태 추적">
    `GET /v1/swap/status/{quoteId}`를 조회하거나, `X-Webhook-Signature` 헤더에 HMAC-SHA256으로 서명된 웹훅을 받습니다.
  </Step>
</Steps>

## 수수료, 한도, 환불

파트너 수수료는 직접 정하고, 키마다 요청 한도가 있습니다.

- **파트너 수수료.** 자체 수수료를 추가할 수 있으며, 각 견적에서 `partner_fee_bps`와 `partner_fee`로 반환됩니다.
- **요청 한도.** 견적 요청과 상태 요청 한도는 파트너별로 정해집니다. 한도를 넘으면 API가 `Retry-After` 헤더와 함께 429를 반환합니다.
- **키 교체.** `POST /v1/partner/rotate-key`로 키를 교체합니다.
- **환불과 실패.** 스왑을 완료할 수 없으면 제공자가 환불 주소로 환불하고 상태가 REFUNDED가 됩니다. 플래그가 지정된 주소는 견적을 받지 못합니다. 도착 후 플래그가 지정된 입금은 환불되지 않고 검토를 위해 보류되며, 사용자가 NEAR Intents 지원팀과 함께 해결합니다. [심사 방식](/ko/products/swap/learn/failed-swaps-and-refunds#how-screening-works)을 참고하세요.

## 자주 묻는 질문

<AccordionGroup>
  <Accordion title="API 키는 어떻게 받나요?">
    API 키는 파트너 온보딩 때 발급됩니다. 이용을 원하시면 [L2Pass 지원팀](/ko/resources/support)에 문의하세요.
  </Accordion>

  <Accordion title="API가 사용자 자금을 보관하나요?">
    아니요. 사용자는 견적용 일회용 입금 주소로 결제하고, 스왑은 NEAR Intents의 솔버가 실행합니다. L2Pass는 사용자의 토큰이나 개인 키를 절대 보관하지 않습니다.
  </Accordion>

  <Accordion title="스왑으로 수수료를 받을 수 있나요?">
    네. 파트너 수수료를 설정하면 각 견적에서 플랫폼 수수료와 함께 `partner_fee_bps`와 `partner_fee`로 반환됩니다.
  </Accordion>

  <Accordion title="SDK가 있나요?">
    네, npm의 `@l2pass/swapkit-sdk`입니다. 자세한 내용은 [API 레퍼런스](https://api.l2pass.com/docs)를 참고하세요.
  </Accordion>
</AccordionGroup>
